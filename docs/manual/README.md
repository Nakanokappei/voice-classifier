All manuals are hand-written per language; technical terms (CLI flags,
column names, etc.) are kept in English for consistency.

## Structure

Every manual follows the same 9 sections:

1. What the tool does
2. Installation
3. First run
4. Column selection (single / multi / interactive)
5. Output layout
6. Key options
7. Configuration (env vars, cache)
8. Troubleshooting
9. Privacy notes
