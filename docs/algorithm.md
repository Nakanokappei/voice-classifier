# Algorithm — チューニング戦略

## 目的

入力テキストの埋め込みに対し、**事前知識なしで** 妥当なクラスタ分割を得る。
ユーザが手法やパラメータを決め打ちしなくても動作することを優先する。

## 評価指標

### 第一指標: シルエットスコア（cosine）

```
silhouette_score(X, labels, metric="cosine")
```

- 範囲: `[-1, 1]`、高いほど良い
- ノイズラベル（`-1`）は計算対象から除外
- 有効クラスタ数が1、または有効サンプル数 < 2 の場合は `-∞` 扱い

### 補助指標（タイブレーク用）

1. **Davies–Bouldin index**（低いほど良い）
2. クラスタサイズの偏り（最大/最小比、小さいほど良い）
3. ノイズ率（低いほど良い、ただし K-Means は常に0）

基本はシルエットスコアのみで選ぶ。
スコアが 0.01 以内で拮抗する場合に限り、補助指標で上位を採用する。

## 候補手法

| 手法 | 特徴 | パラメータ探索 |
|---|---|---|
| **K-Means** | クラスタ数を指定。球状分布が得意 | `k ∈ [min_k, max_k]` |
| **DBSCAN** | 密度ベース。ノイズ検出あり | `eps` をグリッド / `min_samples = max(3, ⌈ln N⌉)` |
| **HDBSCAN** | 階層型密度ベース。クラスタ数自動 | `min_cluster_size` をサンプリング |

すべてコサイン距離で動作させるため、事前に **L2正規化** する。
これにより `euclidean(x, y)² = 2 * (1 - cos_sim(x, y))` で等価換算できる。

## パラメータ探索

### デフォルト範囲

- `min_k = max(2, ⌈√N / 4⌉)`
- `max_k = min(20, ⌈√N⌉)`
- `eps_grid = np.linspace(0.15, 0.60, 10)` （正規化後の距離）
- `min_cluster_size ∈ {max(5, ⌈N/200⌉), max(10, ⌈N/100⌉), max(20, ⌈N/50⌉)}`

### 実行順序

1. K-Means を `k ∈ [min_k, max_k]` で走査
2. DBSCAN を `eps ∈ eps_grid` で走査
3. HDBSCAN を `min_cluster_size ∈ candidates` で走査

各候補ごとにシルエットスコアを算出し、全体で最大の設定を勝者とする。

### サンプリング上限

N が大きい場合（`N > 5000`）、シルエット計算が重いため:
- スコア評価は **ランダム抽出した 2000 点** で実施
- 最終ラベルは全点に適用

## スコア閾値と警告

| シルエットスコア | 判定 |
|---|---|
| `≥ 0.40` | 良好 |
| `0.20 – 0.40` | 許容（レポートにWARNINGを注記） |
| `< 0.20` | 要再検討（レポート先頭に大きく警告） |

閾値は `tuner.py` 内の定数として扱う。

## 再現性

- 乱数種は `random_state=42` で固定（K-Means 初期化など）
- 同じ入力・同じモデルなら結果は決定的になる
